# 巡检系统 · 初始化与使用指南

## 1. 系统初始化（首次部署）

### 1.1 数据库迁移
```bash
python manage.py migrate
```

### 1.2 导入设备、巡检项、分组（种子数据）
```bash
python manage.py seed_inspection --site 化龙
python manage.py seed_inspection --site 知识城
```
此行会创建：
- **CheckItem**：34 条巡检命令项（CPU/内存/风扇/电源/温度/单板/接口/日志/路由/...）
- **DeviceGroup**：按角色分组的设备组（GRP-化龙-防火墙/核心/接入/...）
- **NewDevice**：从 Excel 导入设备，按设备名前缀推导角色、自动填入 `extra` 期望值
- **CheckSet**：全量巡检集 CS-化龙 / CS-知识城

## 2. 真机测试流程

### 2.1 采集原始数据（你的巡检脚本）
```bash
cd C:\Users\ZSS\Desktop\化龙\化龙\化龙配置\network_inspection
python inspection.py --excel 化龙设备清单_带巡检命令.xlsx --commands commands_inspection.yaml --workers 10
```
**重要**：`commands_inspection.yaml` 中路由命令已改为 `display ip routing-table all-vpn-instance`，确保多VPN实例路由全量采集。

### 2.2 拆分输出为单体命令文件
```bash
cd C:\Users\ZSS\Desktop\广期所项目\xunjian\xunjian111\xunjian_system1
python split_raw_output.py --input-dir "C:\Users\ZSS\Desktop\化龙\化龙\化龙配置\network_inspection\inspection_output\化龙设备清单_带巡检命令_2026-07-17_1631" --site 化龙
```
拆分后文件在 `media/raw/化龙/设备名/*.txt`

### 2.3 用 test_checker 逐条验证
**Web 版**：打开 http://localhost:8000/new/tools/test_checker/
- 选择"一键预设" → 自动填入 parser/checker/config
- 粘贴 raw log → 点击"▶ 运行测试" → 立即看到结果

**CLI 版**：
```bash
python manage.py test_checker --input "media\raw\知识城\oasw001...\display_fan.txt" --checker custom --checker-config "{\"func\": \"check_fan\"}"
```

### 2.4 AI 自动分析生成 Excel
在 `media/raw/` 目录准备完整的 raw log 后，说 `@init_checkitems 化龙` 启动 AI 分析 → 自动生成 `巡检项阈值配置表_待审核.xlsx`。

### 2.5 微调阈值
打开生成的 Excel，在**黄色列**填写：
- CPU/内存阈值（如 80%/85%）
- OSPF 邻居期望数（如 2 个 Full）
- BGP 邻居期望数（如 1 个 Established）
- VRRP Master 期望数
- VLAN 集合清单
- 路由期望（下一跳 IP）

### 2.6 导入阈值到系统
微调完成后，在 Web 页面中逐个创建/更新 `CheckItem`，将 Excel 中的 parser/checker/config 填入对应巡检项。

| 字段 | 来源 |
|------|------|
| 命令 | Excel "命令"列 |
| parser | Excel "parser"列 |
| parser_config | Excel "parser_config"列 |
| checker | Excel "checker"列 |
| checker_config | Excel "checker_config"列（**包含现网阈值**） |
| 检查项名称 | Excel "检查项"列 |

> 通过 Web 页面 `/new/checkitem/list/` 逐条手工录入。对于首次部署的用户，用 `seed_inspection.py` 的 `COMMAND_RULES` 字典定义命令规则，再运行 `seed_inspection`。

### 2.7 常见误区澄清
**Q: Excel 中存储的 checker 逻辑是"旧版"还是"新版"？**
A: Excel 只存引用（如 `func: check_fan`），**实际判断代码在 `custom_checks.py` 中**。你改完代码逻辑后，Excel 中相同引用的 checker 都会用新逻辑。不需要额外修改。

**Q: AI 生成的 Excel 会不会覆盖我改好的逻辑？**
A: 不会。AI 生成 Excel 时从 `custom_checks.py` 读取已注册的 checker，匹配合适的引用。你改完代码后，AI 看到的也是最新版。

## 3. 日常使用

### 3.1 执行巡检
打开 Web 页面 `/new/xunjian/` → 选择设备或检查集 → 执行巡检。

### 3.2 查看结果
- **巡检历史**：`/new/history/` → 查看历史记录
- **巡检详情**：点击任意记录 → 查看异常列表
- **文本对比**：点击命令 → 基线 vs 当前的红绿并排 diff 对比（HTML 页面）

### 3.3 确认异常
异常详情页可逐条"确认"或"全部确认"。仅需确认一次，下次巡检无变化不再告警。

### 3.4 设置基线
在历史记录中选择任意一次巡检 → "设为基线"，后续对比基于此基线。
